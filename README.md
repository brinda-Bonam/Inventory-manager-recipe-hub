# Inventory-manager-recipe-hub
A Java desktop application with a Java Swing GUI to let users browse items, track expiry dates, and update stock.  
The backend database uses Microsoft Access, SQL, and JDBC to store inventory data. 
Automated meal planning by integrating a REST API via HTTP requests to generate recipes based on current available pantry ingredients.

How to run Locally:
Download this repository, ensure the access database is located inside your src folder when running,
then run the main java app class in your preferred IDE!

TroubleShooting:
If there are any issues with the images, open the database and check the file locations
The API i used is a free online API and only has 500 uses per month, so please do not spam the application
